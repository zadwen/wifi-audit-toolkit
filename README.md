# Wi-Fi Audit Toolkit

A simple but powerful bash-based Wi-Fi auditing tool.  
Built for **educational purposes only** – use only on networks you **own** or have **explicit permission** to audit.

---

## 💻 Features

- Auto-detects Wi-Fi interface
- Enables monitor mode using `airmon-ng`
- Scans for networks using `airodump-ng`
- Captures WPA2 handshakes
- Deauth attack using `aireplay-ng`
- Cracks captured handshakes using `aircrack-ng`
- Optional auto-auditing using `wifite`

---

## 📦 Requirements

- Kali Linux or other pentesting distro
- Tools: `aircrack-ng`, `wifite`, `gnome-terminal`
- Root access

---

## 🚀 How to Use

```bash
chmod +x wifi_audit_toolkit.sh
sudo ./wifi_audit_toolkit.sh
```
